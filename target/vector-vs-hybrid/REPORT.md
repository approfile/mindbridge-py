# 纯向量与当前混合检索：真实检索消融

日期：2026-10-25。实验重新执行了真实 Chroma 查询、生产融合及本地重排代码；没有修改生产代码、配置、数据库或索引，没有生成回答。

## 对照条件

- 同一冻结 retrieval-v1：52 条合成工程题，44 条可回答、8 条不可回答；11 篇文档、34 个 chunk。
- 分块 512 字符、重叠 64，TopK=4、每路候选 K=16；按原段落 qrels 计分，可回答题取宏平均。
- 同一 `qwen3.7-text-embedding`、1024 维、Chroma cosine。复用上次真实接口生成的 34 个语料向量和 52 个查询向量，在新隔离 SQLite/Chroma 中重新检索；新增 embedding API 请求数为 0。
- 当前融合权重为向量 0.65 / BM25 0.35，开启原有本地词面重排。所有组合均关闭邻居扩展（expand=False），与已有检索评测口径一致。
- “向量＋原重排”只使用向量候选，BM25 不调用且无 BM25 候选进入；向量权重重新分配为 1.0。它仍含原重排的词面特征，不能称为纯向量排序。
- 当前混合方案使用原 `KnowledgeService.retrieve(mode='hybrid')` 入口；其所有主指标精确复现上次 512 混合实验结果。受保护源码、配置、语料和标签哈希均未变化。

## 结果

| 方案 | Recall@4 | Precision@4 | MRR | nDCG@4 | HitRate@4 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 纯向量排序，无 BM25、无重排 | 90.91% | 28.98% | 0.9489 | 0.9029 | 100.00% |
| 向量召回＋原本地重排，无 BM25 | 93.18% | 30.11% | 0.9545 | 0.9195 | 100.00% |
| 向量＋BM25 融合，无重排 | 93.18% | 30.11% | 0.9886 | 0.9506 | 100.00% |
| 当前：向量＋BM25 融合＋原本地重排 | 93.18% | 30.11% | 0.9886 | 0.9560 | 100.00% |

当前方案相对纯向量排序：Recall@4 提高 **2.27 个百分点**，Precision@4 提高 **1.14 个百分点**，MRR 提高 **0.0398**，nDCG@4 提高 **0.0532**。

更严格地控制重排后，当前方案与“向量召回＋原重排”的 Recall/Precision 均值相同，但 MRR 高 0.0341、nDCG 高 0.0365。两者逐题召回并不相同：混合方案 1 题改善、1 题退化、42 题持平。当前证据支持混合方案有排序收益，不能宣称 BM25 在保留同一重排后仍提高了平均召回。

融合无重排与纯向量无重排相比，Recall/Precision 同样提高 2.27 / 1.14 个百分点；当前本地重排在融合之上只进一步提升本次 nDCG（0.9506 → 0.9560），未改变其平均 Recall/Precision/MRR。

## 逐题变化

纯向量排序与当前方案相比，44 条可回答题中，当前方案召回改善 2 题、持平 42 题、退化 0 题。两道改善题各多命中一个已标注段落：

- “低落中出现明确计划、告别语言或无法保证安全时如何升级？”：Recall 从 50% → 100%，Precision 从 25% → 50%；补入 `low-mood-depression-support.md#1`。
- “管理员查看风险台账后应如何避免惩罚、标签化和公开谈资？”：Recall 从 50% → 100%，Precision 从 25% → 50%；补入 `privacy-boundaries-and-ethics.md#0`。

保留原重排、仅去除 BM25 时：

- 上述“管理员查看风险台账”题，混合方案 Recall 100%，向量＋重排 50%。
- “完美主义让我一直拖延，十分钟启动法怎么用？”题，混合方案 Recall 50%，向量＋重排 100%；向量＋重排保留了标注为辅助证据的 `exam-season-guidance.md#0`，融合后它未进入 Top4。

未标注 gain 的片段按现有 qrels 计 0，并不代表它在语义上一定完全无关。

## 解释边界

- 数据由 AI 辅助构造并用于开发，题量小，与知识库同源，标注不穷尽；不代表真实用户分布或独立盲测结果。
- HitRate=100% 只表示每道可回答题至少命中一个标注相关片段，不是全部相关片段都召回，也不是回答正确率。
- 8 条不可回答题四组均返回片段，空检索率均为 0；本实验没有评估生成后的拒答或幻觉。
- 相邻片段扩展未启用，结果不是线上完整上下文覆盖率；没有生成侧/RAGAS 指标。
- 使用已有真实 embedding 缓存可以控制两组输入一致，但没有重新验证 embedding API 的当前可用性，也不测其在线时延和成本。
- 34 块小库不能用于判断大规模 ANN/HNSW 的性能。
