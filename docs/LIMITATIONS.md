# 已知边界与改进顺序

版本核对日期：2026-10-30。以下问题仍未修复，发布最新代码不等于质量指标已达标。

| 优先级 | 问题 | 下一步与验收 |
| --- | --- | --- |
| P0 | 问句覆盖会话事实、英文句尾标点污染值 | 仅从明确陈述更新，保留纠正/遗忘语义；同时检查回复与更新后 SQL，冻结原标签回归 |
| P0 | 否认危险分支将部分咨询误分 CHAT | 分离风险否认与咨询诉求；保留文学引用/论文等边界对照，不修改 gold 凑成绩 |
| P1 | 高风险回复不足或无依据的完成声明 | 逐条复核人工分歧，约束实际工具证据，分别评估充分性、安全性、完成声明 |
| P1 | 生成/审核网络超时与波动 | 整轮预算内有限重试、故障分类与幂等；保留首轮和失败，不挑最佳试次 |
| P1 | RAG 证据约束与 60 字符改写截断 | 人工核对 claim 支持，再区分同理表达与事实建议；按上下文预算优化，不追求单一 judge 高分 |
| P2 | 在线 token/成本缺失 | 接入真实 provider usage 与版本化价格；缺失值仍记 unknown，逻辑调用数不冒充 token |
| P2 | 自动评测与复现 | 分层 CI、artifact/阈值、judge 校准；移除历史私有缓存硬依赖，另建未用于调优的保留集 |
| P2 | 对比证据不足 | 同数据、同预算比较模型与编排 baseline；顺序基线不是单次 LLM，也尚无严格计算量匹配结论 |

部署边界：准入/同会话互斥和邮件限流按进程/Worker；不是多副本统一配额。租约与执行审计已实现，但 SMTP 收件后提交前仍有重复窗口，不能承诺 exactly-once。

隐私边界：本地密钥非 KMS，未完成自动轮换；历史备份不因迁移自动擦除；敏感读取权限未细化到组织/个案；保留清理是显式离线操作。加密、审计不构成合规认证或临床安全证明。

模型边界：当前实测是 DeepSeek API，embedding 为 Qwen API；没有完成 Qwen3.5-4B 本地部署、独立微调或最强模型横评。旧命名 Modelfile 不证明有训练产物。
