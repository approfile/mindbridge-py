# 已知边界与改进顺序

版本核对日期：2026-10-31。P0/P1 五项工程改进已实现并开展真实回归，细节与结果见 [本轮记录](p0p1-hardening-20261031.md)。实现门槛不等于所有自然输入的质量问题全部消失。

| 范围 | 当前状态 | 下一步 |
| --- | --- | --- |
| 会话事实 | 已修复已知问句覆盖、英语句尾标点，支持旧派生状态版本重建 | 扩充真实语言变化；保守白名单仍非通用事实理解 |
| 危险否认后的咨询 | 已将个人困扰/支持诉求纳入该分支，保留普通/学术任务边界 | 更大、独立的咨询边界样本复核；不能由开发集推断临床识别率 |
| 高风险充分性与完成声明 | 增强中英兜底、具体动作与完成声明检查 | 对新兜底重做人工/专家复核，继续分析误拦与未覆盖表达 |
| 生成 / 审核可靠性 | 新增共享预算内分类重试、部分输出丢弃与不完整 SSE 检测 | 持续监测超时/重试/兜底；不能保证上游立即停止计费 |
| RAG 证据约束 | 移除 60 字前缀截断，加入显式窗口与逐句来源核验 | 语义支持仍依赖评审模型，严格门槛也可能造成兜底；扩充独立评测并校准 judge |
| 在线 token/成本 | 已接入真实 usage、逐次请求账本、版本化价格与独立缓存指标，并完成[系统基准](SYSTEM-BENCHMARK.md) | 尚未做账单对账；价格过期/时段不确定保留 unknown，自部署基础设施成本未配置 |
| 自动评测与复现 | 离线 CI 已有；真实评测仍需单独执行，历史适配器依赖私有缓存 | 独立质量流水线、报告归档和可配置缓存/在线重建；另建未调优的保留集 |
| 模型 / 编排对比 | 严格同预算证据不足 | 比较未微调模型、提示词基线、训练版本与编排基线；不靠术语证明收益 |
| 1/2/4 并发基准 | 已复现并修复已知记忆初始化间隙锁死锁；相同122次HTTP对照中未再出现，见[修复记录](BASELINE-RELIABILITY.md) | 继续监测其他锁序及扩大压测；当前闭环小样本不是最大容量或多副本结论 |
| 空证据与评分有效性 | 修复否定承诺误拦；同评审器空证据契约12/12通过，旧/新样本裁决有效性均100/100 | 自然任务仍有兜底；同源评审尚未专家校准，不能把裁决有效等同判断准确 |

部署边界：准入/同会话互斥和邮件限流按进程/Worker；不是多副本统一配额。租约与执行审计已实现，但 SMTP 收件后提交前仍有重复窗口，不能承诺 exactly-once。

隐私边界：本地密钥非 KMS，未完成自动轮换；历史备份不因迁移自动擦除；敏感读取权限未细化到组织/个案；保留清理是显式离线操作。加密、审计不构成合规认证或临床安全证明。

模型边界：当前实测是 DeepSeek API，embedding 为 Qwen API；没有完成 Qwen3.5-4B 本地部署、独立 SFT/GRPO 训练或最强模型横评。旧命名 Modelfile 不证明有训练产物。
