# 测试与质量证据

当前测试使用 unittest，运行命令见[开发文档](DEVELOPMENT.md)。6 组工程 Harness 覆盖风险、路由、Skills、检索、HTTP/API 与队列。测试数量以本次发布验证记录为准，不沿用旧首页“23 个测试”。

Agent 评估区分可控故障、真实自然任务、真实上下文干预、独立模型语义评审、RAGAS 与真实人工意见。SQL job SUCCESS 不自动证明 Excel/邮件已发生；实际执行采集会重新打开工作簿、查本机 Mailpit，并核对报告/任务/副作用关系。[详细结果](BENCHMARKS.md)。

unknown 不从分母删除；不适用项与失败不同。裁决绑定观察快照与可见正文，旧正文的审核不能放行新正文。业务安全门槛通过不替代独立质量评估。

GitHub Actions 只运行离线确定性测试及 Harness，不调用付费模型，也没有把本机历史真实评测变成 CI 最新成绩。模型质量、生产环境和部署验证应分别报告。
