# 记忆与 Skills

近期消息使用 Redis，默认最多 40 条、TTL 24 小时；SQL 保存完整消息与会话级摘要/事实。默认摘要最多 500 字符、近期窗口 8 条；事实附带同一用户、同一会话的用户消息来源。它是有界会话记忆，不是任意跨会话长期记忆。[原实现记录](p1-memory-safety-evaluation.md)。

当前确定性缺陷仍存在：项目代号/目标岗位的问句可覆盖既有事实，英文句末点号可进入事实值。来源验证只证明内容来自该用户消息，不证明它是有效事实陈述。可见回复正确也可能伴随错误持久状态，必须同时检查 SQL。

skills/ 中有 7 个标准 Skill：基础支持、高风险安全计划、焦虑稳定化、睡眠作息、学业压力拆解、资源转介和辅导员交接摘要。Skill 是服务端选择并组装的提示约束，不是任意外部 Skill 自动执行或进程沙箱。
