## 产品使用

学生登录后点击“模型设置”。

- 自填 API Key：首版支持 DeepSeek / 阿里云 DashScope 对话，DashScope embedding；也可明确搭配管理员配置的自部署连接。两种 Key 分开填写。
- 完整自部署：生成、理解、风险、审核、改写、摘要及 embedding 均使用自部署服务，无自动云端切换。
- 测试连接：实际检查普通完成、JSON 完成、异步审核 JSON、流式结束、thinking 输出与向量维度，不会保存配置。
- 测试并保存：重新测试，建立并核对独立的知识库索引后激活新版本。失败时旧配置继续有效。
- 留空 Key：仅对相同连接保留已保存的 Key；换服务后必须重新填写。撤销个人配置会清除已保存凭据并恢复部署默认配置，版本继续递增。

测试使用合成文本，会产生少量模型调用费用；保存还可能产生知识库 embedding 费用。运行中的轮次保持原快照，新的设置从下一轮生效。

## 服务端边界

`user_model_profiles.config_json` 使用现有独立文件密钥的 Fernet 加密。凭据、连接绑定和能力检测结果一起存储。接口仅输出白名单字段与“已保存”标记，不返回 Key；不在浏览器存储模型 Key。沿用项目现有的账号认证；远程公开部署需要 HTTPS。

用户只能选择服务目录里的连接 ID，不能提交任意 URL。自部署 URL / 服务 Key / 模型 revision 由部署者配置。修改地址、模型 revision 后，原连接须重新测试保存；当前轮次仍使用已解析的地址和凭据。

保存使用条件更新比较版本；撤销保留不含凭据的版本墓碑，防止旧保存请求在撤销后恢复 Key。配置请求体上限 16KiB，单进程最多两个测试/保存请求。应用与 GPU 的跨进程限流仍属于后续容量建设范围。

每轮在 owned planning worker 中一次性解析配置，传入整个 Harness 和正文审核。覆盖旧的角色 provider/model 配置，禁止安全审核等角色意外保留云连接。trace 与用量 attempt 记录 profile ID / revision / mode，均不含凭据。

## 索引

新索引绑定公共校园知识库作用域、凭据所有者、embedding 服务地址/版本、模型、维度、查询 instruction、切块配置及语料哈希。生成模型单独切换可复用当前 embedding 索引；不同用户或 embedding 身份不能复用。

Chroma 集合名称由绑定与语料哈希生成。只从同一集合读取文档向量缓存；忽略旧的无模型身份 `KnowledgeChunk.embedding_json`。部署默认配置也使用命名空间，`.env` 切换 embedding 后不会沿用旧向量。

现有知识库仍为管理员维护的公共语料，尚未新增用户私有知识库上传。旧集合保留以支持在途请求；自动回收、配额与长期存储治理尚未实现。语料在保存过程中变化时不激活候选；管理员更新语料时构建独立集合再提交，不修改在途请求的旧集合。其他账号的索引在需要检索新语料时构建。首版没有跨语料版本的文档向量复用，语料更新会产生完整重建费用，留待后续基于实测优化。

## 能力与成本

自部署要求 `/v1/models` 声明至少 8192 token 上下文；这只是服务声明核验，不是满窗口压力测试。云端未提供声明时显示 unknown。实际超出窗口的请求由模型服务拒绝，系统失败关闭，不静默截断或切换供应商。

模型能力检查不保证心理支持效果。规则、正文审核、RAG 依据和原有工具治理继续生效。固定安全兜底不等于模型成功，也不等于临床安全证明。

自部署继续记录供应商返回的 token；缺失 usage 或缓存拆分仍是 unknown。GPU 时间成本尚未配置时不会记作零。云端使用版本化公开价格估算，不等于账单。后续真实对照必须另外记录租卡时长、空闲、利用率与成功请求数。

## 接口

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/model-profile/connections` | 可用连接目录，不含服务 Key |
| GET | `/api/model-profile` | 当前账号的脱敏配置 |
| POST | `/api/model-profile/test` | 测试候选配置，不保存 |
| PUT | `/api/model-profile` | 测试、建索引、按版本激活 |
| DELETE | `/api/model-profile?revision=N` | 撤销凭据，保留递增版本墓碑 |

PUT/POST 结构：`expected_revision`、`mode`（`api` / `selfhost`）、`chat` / `embedding`（各含 `connection`、`model`、可选 `api_key`）和 `embedding_dimensions`。请求体不得记录进日志。

部署和租机操作见 [AutoDL 操作手册](AUTODL.md)。
