# 设计取舍

当前版本的设计事实以[架构](ARCHITECTURE.md)、[安全](SAFETY.md)、[RAG](RAG.md)和源码为准。

- 共享黑板让任务依赖、认领、风险覆盖与产物来源显式可查；并不证明优于所有框架或顺序工作流，需要同预算消融。
- 计划契约与正文审核分开，避免拿准备状态替代真实回复证据。先生成再审核的代价是首块延迟更长。
- 报告/outbox 事务解耦回复与工具执行，避免断连丢任务；外部邮件投递仍非 exactly-once。
- 混合召回保留语义与词面互补；本地重排成本低，但不是神经 cross-encoder，也未证明大库吞吐。
- 会话事实保存来源有助于审计，但来源真实不保证抽取语义正确；新评测已经暴露问句污染。
- API 模型便于先验证系统链路；Ollama 是可选适配，没有因此宣称本地模型或微调训练完成。
